Domain Name System (DNS)

DNS translates human-friendly names like example.com into IP addresses that computers use to connect. When you type a website name, your device asks a DNS resolver, usually run by your internet provider or a public service, for the matching address.

If the resolver does not have the answer cached, it asks the root servers, then the top-level domain servers (such as .com), and finally the domain's authoritative name server.

Answers are cached for a period set by the TTL (time to live) value, so repeated lookups are fast. Common record types are A (IPv4 address), AAAA (IPv6 address), CNAME (alias to another name), and MX (mail server).
